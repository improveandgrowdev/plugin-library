Plugin Library

The WordPress plugins, themes and Elementor widgets our team has built. Each card covers what it does, what it needs, and where to get it.

Downloads need GitHub access. Every plugin lives in a private repo under improveandgrowdev. Sign in to GitHub with an account that has access, or the download link shows a 404. To install: Plugins → Add New → Upload Plugin, choose the zip, then Activate.
Maintained by the Improve & Grow dev team. To add a plugin, edit the PLUGINS list in index.html in the plugin-library repo.
